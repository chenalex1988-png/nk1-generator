## 一、工單原定（逐項照抄意思，不改數字）

**群別**
- **A**＝NK／LLM 程式輸出 docx：docProps `creator` 空 **且** `created`＝1970 epoch
- **B**＝真人 Word 建檔 docx：`creator` 非空 **且** 時間真實
- **C**＝其餘：審閱回饋、加密、待查

**範圍**
- 核心 E1＋E2＝`T023／T024／T025／T026／T027`、`T002`（T023／T025／T026 依檔名補列，不靠關鍵詞）
- 第二圈 E3＝`T003`～`T008`
- E4／E5／E6 只列不跑

**門檻（不自調）**

| 項 | 門檻 |
|---|---|
| R1 | 節 ≥5 且節名重合 ≥60% |
| R2 固定節 | 相似度 ≥80% 且 ≥2 節 |
| R3 變數節 | 相似度 ≤40% 的節 ≥1，且欄位候選 ≥5 |
| R4 | 每類 ≥1 條法規含條號 |
| R5 | ≥1 份審閱回饋 |
| R6 | ≥1 組配對 |

**判定**：R1、R3、R6 全過＝**夠**；R6 缺＝**可用但要補**；R1 或 R3 缺＝**不夠**。

**配對三種並列（都只出統計）**：(i) A→B 同夾；(ii) prompt 節→B 節（結構重合率）；
(iii) B 群內版本對版本（同夾多版），標「客戶成品版本間，非三顧模板配對」；(iii) 分布另表、不計入總測。

## 三、工單未明寫、由阿K 定的口徑 🔶

> 這些是**計算方式**，不是門檻；門檻數字一個都沒動。要改哪條，改這裡＋JSON，一條指令重跑。

1. **節名重合率＝Jaccard**（交集／聯集），與 v1.0 同法。
2. **R1「節 ≥5」＝兩側節數皆 ≥5**；R1 可由 (i) 或 (ii) 過關，**(iii) 不算 R1**（同文件兩版的骨架重合沒有鑑別力）。
3. **R2／R3 可由 (i) 或 (iii) 過關，R6 只算 (i)**。
   理由：判定式裡「R6 缺＝可用但要補」要成立，R3 就得能在沒有 (i) 時算得出來——只有 (iii) 做得到。
   用 (iii) 辨識固定節／變數節是**結構統計**，**不等於**把客戶成品當驗收配對（那是 Alex 的題，本口徑不碰）。
   報告中每個 ✅ 都標出由哪種配對過關。
4. **R3「欄位候選」＝節內「數值＋單位／型號樣式／日期／職稱」四計數之和，取兩側較大者**。
5. **R4「含條號」＝命中字串含「第…條」、「21 CFR x.y」或「§」**；只有法規名、Annex／Part 號不算條號。
6. **類層級**：R1／R2／R3 任一夾過即該類過；R4 取該類去重後含條號法規數；R5、R6 取該類合計。
7. **總測**：核心類全「夠」＝成立；核心類任一「不夠」＝不成立；其餘＝不明。
8. **prompt 樣式 2**（改動 1）只套 `LC-EN-` 且樣式 1＝0 的夾；抽取＝條列符號、編號（含行內、含 X.Y 多層）、冒號前段。
9. **節名零原句**：計算用節鍵（≤20 字）與顯示用節名分開；像句子（含逗句號、語助詞等）或去括號後中文 >8 字者**只計不列**；機構名、非標題字彙英文詞遮蔽。
10. **E4／E5／E6 只列不跑**：v1.0 的對照組 T022、T029、T064 落在這三類或範圍外，**v1.1 不跑對照組**（依本工單「只列不跑」；v1.0 數字仍在 v1.0 報告）。
