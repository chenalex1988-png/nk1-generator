# NK1 管線改寫模型輸出的原則（M4.4；Alex 2026-09-28 同意）

## 原則
管線改動模型輸出，**只准以下三種情況同時成立**：
1. **只改寫法、不改內容**
2. **每一項可查表驗證**
3. **原文與改後都留紀錄**

**不滿足任一項，就攔，不改。**

## 目前唯一的改寫：條號範圍展開（`scripts/nk1-expand.py`）
| 項 | 規則 |
|---|---|
| 辨識 | 「X 至 Y」「X–Y」「X~Y」「X-Y」，X、Y 皆為「章.條」且同章 |
| 展開條件（三項全滿足） | X 在條號表；Y 在條號表；X 到 Y 之間每一個連號（同章、條號遞增 1）都在條號表 |
| 寫回 | 「X、X+1、…、Y」逐條寫回正文，其餘文字不動 |
| 紀錄 | 內容包 `normalizations`：`{section_id, kind:"clause_range", original, expanded[], table_check:"all_present"}`；未展開者 `table_check:"missing:[條號]", action:"regen"` |
| 展開後 | 照常過五類掃描與分段允收閘（**展開不是免檢**） |
| 不滿足 | 不展開 → 重生 ≤2 次（換 seed，改寫說明加「條號逐條列出，只可引用允許清單內的條號」）→ 仍含範圍或表外條號即攔 |

## 對照三條件
- 只改寫法：範圍與逐條列舉指涉同一組條號，條號集合不增不減。
- 可查表：每一個展開出的條號都在 `specs/refs/annex15_v0.yaml` 內（查不到就不展開）。
- 留紀錄：`original` 與 `expanded[]` 同列於內容包。
