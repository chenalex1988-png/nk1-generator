# NK1 提示 v1 規格（M5.5 D；只寫規格，未跑）

> 對照現行：`scripts/nk1-gen.py` v0.11 的 `SYSTEM_V2` 與 policy 模式每節輸入。

## 一、系統提示（v1 條文）

| # | 條文 | 對應退件理由 |
|---|---|---|
| P1 | 正文**不寫條號、不寫法規名、不寫法規條文或其譯文**；需要依據時只寫「依參考資料」或不寫 | ③（修訂） |
| P2 | 引用**只進 refs**（law、clause、version 皆必填）；refs 供審閱，不出現在正文 | ③ |
| P3 | 計畫類文件**不寫任何結果或判定**（不得出現已完成、已核准、均符合、無中斷、偏離 N 件、依…結果 等）；本文件是執行前的計畫 | ① |
| P4 | 允收標準一律**規範式**：「允收：…應 ≤ …／應為 …／不得超過 …／須於 … 內」；不得寫成陳述句 | ①② |
| P5 | **核准日只進核准表格**，敘述句不寫日期＋核准 | ② |
| P6 | 數值、編號、日期只能取自「本節可用資料」，且依其用途使用；同一值不得表示不同意義 | ② |
| P7 | 方法步驟**編號條列**（1. 2. 3.），每步含量測點位置、儀器與校正狀態、取樣頻率、執行次數（性能驗證另含負載定義），皆取自資料表方法欄 | ④⑦ |
| P8 | 不重複設備名稱與資產編號（僅首次出現於目的節）；不寫冗餘敘述 | ⑦ |
| P9 | 不合格處理一律指向資料表的偏差處理程序 SOP 編號 | ⑥ |
| P10 | 繁體中文；數量用阿拉伯數字並照資料表原樣寫（例：1 次） | （沿用 v0.9） |

## 二、每節輸入（相對 v0.11 的改動）

| 欄 | v0.11 | v1 |
